# **Rotation Span Task**

Assessed WMC through arrow-sequence recall combined with interleaved rotation judgments.

This task consisted of three familiarisation blocks followed by an experimental task.


### ⚙️ **Familiarisation**

#### **Block 1 – Arrow recall:**

* Recall sequences of arrows varying in length (short or long) and direction (eight possible orientations).
* Three sets: two of size 2 and one of size 3.

#### **Block 2 – Rotation judgment:**

* Complete 15 trials judging whether rotated letters (F, G, J, R) were forward-facing or mirror-reversed in their upright orientation.
* Repeat until ≥85% accuracy.
* Response time limit calculation: Mean time from letter presentation to clicking "continue" + 2.5 SD.

#### **Block 3 – Combined task:**

* Alternate between rotation judgments and red-square presentations (650 ms), followed by serial recall.
* Three sets: two of size 2 and one of size 3.
* Response time limit application: The limit calculated in Block 2 was applied. Rotation judgments exceeding this limit triggered automatic progression to the next arrow presentation.

### ⚙️ **Experimental Task**

* Followed the same procedure as Familarisation Block 3.
* Three blocks, each containing four set sizes (2–5), presented in random order within each block.
