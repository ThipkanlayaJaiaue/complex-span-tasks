# **Symmetry Span Task**

This task contains 3 familarisation blocks and an experimental task

### **Familiarisation**

#### **Block 1 – Spatial recall:**

* Recall red-square sequences (650 ms per square) presented in a 4 × 4 grid.
* Three sets: two of size 2 and one of size 3.

#### **Block 2 – Symmetry judgment:**

* Complete 15 trials judging vertical symmetry in an 8 × 8 grid.
* Repeat until ≥85% accuracy.
* Response time limit calculation: Mean time from grid presentation to clicking "continue" + 2.5 SD.

#### **Block 3 – Combined task:**

* Alternate between symmetry judgments and red-square presentations (650 ms), followed by serial recall.
* Three sets: two of size 2 and one of size 3.
* Response time limit application: The limit calculated in Block 2 was applied. Symmetry judgments exceeding this limit triggered automatic progression to the next red-square presentation.

### **Experimental Task**

* Followed the same procedure as Familarisation Block 3.
* Three blocks, each containing four set sizes (2–5; Set sizes presented in random order).
